# Contributing

Thanks for helping improve CCA Prep.

## Local setup

```bash
npm ci
npm run dev
```

Before opening a pull request, run:

```bash
npm run lint
npm run build
```

## Content changes

This project is an independent study aid. When changing exam-domain material:

- Prefer primary Anthropic documentation as the source of truth.
- Do not present unofficial guidance as an exam guarantee.
- Keep questions and explanations focused on durable concepts rather than memorized answer keys.
- Do not add proprietary, leaked, or exam-confidential material.

## Pull requests

Keep changes focused and explain what changed, why it is useful, and how you verified it. Do not commit API keys, credentials, local environment files, or generated build output.
